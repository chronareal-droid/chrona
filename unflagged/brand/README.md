# Unflagged brand

**Name:** Unflagged · **Tagline:** Monetization pre-check for faceless creators

| File | Use |
|------|-----|
| `png/unflagged-avatar-1024.png` | Profile picture (Instagram, TikTok, YouTube). Safe for circular crops. |
| `unflagged-mark.svg`, `png/unflagged-mark-512.png` | The mark on its own (transparent background). |
| `unflagged-mark-inverse.svg`, `png/unflagged-mark-inverse-512.png` | Dark square, lime check (the favicon / app icon look). |
| `unflagged-wordmark-on-dark.svg` / `.png` | Mark + name, white text, for dark backgrounds. |
| `unflagged-wordmark-on-light.svg` / `.png` | Mark + name, dark text, for light backgrounds. |

Colours: lime `#a3e635`, ink `#0b0f14`, white `#f6f7f9`. The name is set in Inter ExtraBold and converted to
outlines, so the SVGs look the same everywhere without the font installed.
